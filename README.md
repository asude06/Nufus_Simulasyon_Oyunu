# Nufus_Simulasyon_Oyunu
Oyunun yapısal olarak nesne yönelimli programlama ile Eclipse ortamında derlenen dinamik bir nüfus  değiştirme simülasyonudur. Şehir, İlçe, Mahalle, Kişi hiyerarşisi bulunmakta. 
Java’nın kullanıma sunduğu 
kapsülleme ile nesnelerime ait private verileri diğer nesnelerin de kullanabilmesi adına dışardan dolaylı bir erişim 
sağladım. Bir diğer sunduğu Bileşim ile sahiplik durumu sağladım. Örnek olarak şehir içinde liste halinde 
ilçelerin bulunması ve ondan oluşması.
